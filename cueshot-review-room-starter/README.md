# CueShot Review Room Starter

Free starter version for AI video QC.

## What it does

```text
video/keyframes + goal → visible-evidence review → Hold/Ship decision → basic repair prompt
```

## Best for

- single clip review
- simple keyframe review
- identifying obvious AI artifacts
- turning “feels fake” into visible evidence

## Upgrade path

The Pro version adds multi-candidate ranking, timecode-level issue tables, batch reports, repair queues, and production-oriented release decisions.
