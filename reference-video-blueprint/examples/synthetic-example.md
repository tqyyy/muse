# Synthetic Example

This example uses a two-second synthetic black-to-white test clip created locally by the test suite. It contains no third-party video, music, people, brands, or dialogue.

## Study goal

Learn how a sharp visual contrast can function as a first-frame pattern interrupt for an original vertical product explainer.

## Original adaptation

- Do not reproduce the test clip as a campaign asset.
- Replace the contrast with a brand-owned product state change.
- Use original copy and either original or licensed sound.
- Add a visible result viewers can wait for within the next 2–3 seconds.
