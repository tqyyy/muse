# CueShot Shot Designer Starter

Free starter version for AI video shot planning.

## What it does

```text
rough idea → shot mode → shot plan → model-neutral AI video prompt
```

## Example input

```text
A student stands outside a rainy convenience store at night, holding food, suddenly remembering home.
```

## Example output shape

- Shot mode: single shot or 2–3 shots.
- Shot plan: camera, blocking, lighting, continuity.
- Prompt: concrete visual instructions.
- Negative constraints: identity drift, extra people, text/logo artifacts.

## Upgrade path

The Pro version adds 23 director-inspired visual language profiles, model-specific prompt adaptation, multiple alternatives, and production-ready packaging.
