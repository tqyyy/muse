# 一致性一号（Consistency Auditor）V1.0.0

专门检查 AI 漫剧/视频中：
- 人物是否与定妆图一致；
- 脸型、五官、发型、体型是否发生漂移；
- 服装、妆容、配饰是否保持一致；
- 场景结构、家具、背景陈设、灯光是否与场景基准一致；
- 道具状态、人物位置、视线和动作是否在前后镜头间连续。

## 文件结构

- `SKILL.md`：核心工作规范与报告格式
- `references/visual-baseline-template.md`：角色/场景/道具视觉基准登记模板
- `references/shot-continuity-checklist.md`：逐镜审核清单

## 使用前准备

尽量同时提供：
1. 已锁定的角色定妆图；
2. 已锁定的场景基准图；
3. 分镜表或镜头编号/时间码；
4. 待审核视频；
5. 必要的前后镜头；
6. 明确允许的换装、转场、时间跳跃等变化。

如果只提供视频而没有定妆图/场景基准图，Skill 可以检查镜头之间是否一致，但不能可靠证明它是否符合原始定妆和场景设计。

## 与现有 Skill 的分工

- 剧本一号：创作剧本、角色/场景设定、分镜和初始生成提示词。
- 剧情审核：判断成片是否符合剧情。
- 一致性一号：审核人物定妆、脸型身份、场景、道具和跨镜头视觉连续性。
- 原有制作质量 QC：审核剪辑、声音、技术质量。
- 返修一号：接收缺陷清单，制定返修方案并生成 Muse 提示词。

一致性一号只负责审查和结构化交接，不自动修改视频，也不宣称已在 Muse 中安装或自动运行。
