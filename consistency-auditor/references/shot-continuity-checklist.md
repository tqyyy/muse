# 逐镜连续性检查清单

每个镜头逐项填写“符合 / 不符合 / 无法确认 / 不适用”。

## 人物
- [ ] 角色身份与参考定妆一致
- [ ] 脸型轮廓与五官比例稳定
- [ ] 发际线、发型、发色、发饰一致
- [ ] 肤色、年龄感、固定标志一致
- [ ] 身高感、体型、肩宽和整体剪影一致
- [ ] 服装款式、颜色、材质、穿法一致
- [ ] 配饰、鞋袜、妆容等一致
- [ ] 污渍、破损、湿润等状态符合剧情进度

## 场景
- [ ] 场景结构与基准图一致
- [ ] 门窗、入口、家具和大型陈设位置一致
- [ ] 关键背景物件数量、位置和朝向一致
- [ ] 材质、纹理、颜色没有无故漂移
- [ ] 光源方向、阴影、时间和天气合理
- [ ] 机位变化没有造成不合理的空间关系跳变

## 道具
- [ ] 道具外观和数量一致
- [ ] 持有人、左右手、放置位置连续
- [ ] 开合、开关、破损、内容等状态连续
- [ ] 动作导致的状态变化合理

## 镜头衔接
- [ ] 人物位置、朝向、视线与上一镜头衔接
- [ ] 动作起止状态连续
- [ ] 人物与场景关键物件的相对位置连续
- [ ] 出入画方向与空间轴线合理
- [ ] 若发生变化，分镜/剧情中有明确依据
