# 返修诊断框架

## 问题拆解
每条问题至少写清：
1. 观众看到/听到什么（现象）。
2. 它为什么会发生（生成或设计机制）。
3. 上游根因在哪里（剧本/分镜/表演/提示词/模型/剪辑/声音/资产）。
4. 对剧情理解、人物可信度、空间理解、节奏或沉浸感造成什么影响。
5. 哪些证据支持该判断，哪些仍待核验。

## 动作连续性五段法
- 预备：人物原本在做什么，注意力在哪里。
- 触发：什么刺激导致动作开始。
- 起势：身体如何准备，重心如何变化。
- 执行：动作路径、速度、接触与反作用。
- 收势：动作如何减速、停下，人物状态如何留给下一镜。

不是每个动作都必须五段平均分配时长；根据动作复杂度和剧情节奏分配。

## 跨镜状态链
上一镜出口 → 当前镜入口 → 当前镜出口 → 下一镜入口。
至少比对：
- 人物位置/朝向/视线/姿态/动作阶段；
- 道具持有者/手别/开合状态/接触点；
- 场景空间/轴线/屏幕方向；
- 摄影机位置/景别/运动方向；
- 声音延续/切断/先行；
- 时间连续性和剧情因果。

## 镜头流畅性诊断
区分：
- 主体运动不流畅；
- 摄影机运动不流畅；
- 主体与摄影机运动关系不协调；
- 剪辑切点不流畅；
- 动作时间不足或节奏不匹配；
- 镜头空间关系不清；
- 声画不同步。

禁止把以上不同问题统一写成“镜头不流畅”。

## 返修策略决策
- 提示词局部修订：意图与分镜正确，执行描述不充分。
- 整镜重生成：关键动作/人物/空间画面已严重失真。
- 前后镜联动：单镜修复无法维持跨镜状态。
- 退回分镜：镜头设计本身无法容纳动作、时长或构图。
- 退回剧本/资产/声音：根因不属于生成提示词。
